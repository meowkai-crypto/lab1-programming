## 🚀 Как запустить

### Требования
- Компилятор g++ (MinGW-w64)
- VS Code с расширением C/C++

### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -o app main.cpp
./app        # Linux/macOS
app.exe      # Windows
```
